## Rollback local

Image trước deploy được giữ bằng tag `html-share-studio:rollback-20261008-1ecca3aa`, ID `sha256:1ecca3aa575c3a5a0dc18b8170d0aa19a7d7d73f7d575dd2ad257432145a4039`. Đã kiểm tra tag trỏ đúng image cũ; chưa thực hiện rollback vì deploy mới healthy.

```powershell
$labRoot = 'C:/Users/admin/Documents/Codex/html-share-platform-local-mvp'
$uiRoot = 'C:/Users/admin/Documents/Codex/html-share-platform-pr5-sync'
$env:STUDIO_WEB_IMAGE = 'html-share-studio:rollback-20261008-1ecca3aa'
docker compose -p html-share-local-mvp --project-directory $labRoot --env-file "$labRoot/.env" -f "$labRoot/compose.yaml" -f "$uiRoot/compose.studio-ui.yaml" up -d --no-deps --no-build web
```

Để trở lại Studio mới, dùng cùng lệnh với `STUDIO_WEB_IMAGE=html-share-studio:ui-908901b`. Giữ override ở những lần vận hành tiếp theo; checkout lab cũ chưa có UI mới.
